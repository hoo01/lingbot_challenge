# E1 15000 步最终评测报告

报告日期：2026-10-13，Asia/Shanghai。本文依据已经保存的训练交接、接收验收和完成回执编写，并在本地重新核对文件 SHA 与逐回合统计；本次写报告没有重新运行模型、仿真或远端评测。

**E1 完成 500 个固定场景的完整策略执行，0 个超时零分，51 个成功，成功率 10.2%。** 同一冻结清单上的历史 E0 为 54/500（10.8%），E1 少 3 次成功，差 −0.6 个百分点；本轮没有观察到总体成功率提升。

E1 自己的归一化、相对关节还原和固定输入已经核验。现有证据支持优先排查训练及模型侧，但尚未定位到 E1 的具体训练错误，也不能仅凭低分认定相对动作方法无效。E0 历史 BF16 与 E1 FP32、模型采样随机流及训练端完整动作审计缺口限制了因果解释。本报告是队内开发评测，不是正式竞赛成绩。

## 3. 归一化与物理动作：已经通过的检查

E1 使用自己的相对动作统计，没有混用 F1/E0 的绝对动作 norm，也没有使用旧 Lab 的 MeanStd norm。

| 字段 | 表示与统计维度 |
| --- | --- |
| 12 维机械臂 action | 相对当前状态；每个 horizon 分别 `bounds_99_woclip`，`[50,12]` |
| 12 维机械臂 state | 绝对状态，`[12]` |
| 2 维夹爪 action/state | 绝对值，`bounds_99_woclip`，`[2]` |
| 原始物理顺序 | 左臂 `0:6`、左夹爪 `6`、右臂 `7:13`、右夹爪 `13` |
| 模型 / 物理输出 | 规范动作 `[50,55]`，去 padding 后 `[50,14]` |

对于窗口内第 h 个绝对机械臂目标 `a_h`，相对表示为 `Δq_h = a_h − q_t`。推理逆变换按 h 对应的统计量反归一化，再计算 `target_h = q_t + Δq_h`。50 个目标各加回同一次当前观测 `q_t`，不沿预测时间累加；夹爪不加状态。

- norm SHA256：`7e6ac279d147cb8422108d36216768111c19bb2113ca9eee1a23df22df238df0`。
- 实际生效 robot YAML SHA256：`49d07e5dcff216df70abfed89c2eaf13c6a2aa12eba3d024d7b83a89e3bf70b5`。
- 两卡 runtime 均确认机械臂 `subtract_state=true / relative_type=joint_delta`，夹爪 `subtract_state=false`，统计形状与 E1 相符。
- 使用实际官方 apply/unapply 的非对称左右臂、50 个不同目标 CPU 往返，物理目标最大误差为 `3.313319476561105e-7`，小于核验容差 `atol=rtol=1e-6`；夹爪保持绝对值。

证据包括[模型 norm](../../train/evidence/e1_shuweilin_20261011_080143/assets/norm_stats.json)、[有效 robot YAML](../../train/evidence/e1_shuweilin_20261011_080143/configs/robot_configs/robotwin.yaml)、[动作映射回执](e1-15000-completed-20261013/recipient-action-mapping.json)和[两卡 runtime 完成核验](e1-15000-completed-20261013/verification.json)。CPU inverse 输出为 float64 是该统计量下的记录结果，不代表模型参数改为 float64。

已跟踪的训练证据在 Windows 工作区经过 Git 的 LF→CRLF 转换；本地报告核验按归档 LF 字节计算这些文件的哈希，norm 仍与原 provenance SHA 一致，不修改训练文件。评测进程实际加载 norm 的 SHA 来自原 runtime 回执。新收入本报告的原完成证据设置为不转换换行，保持 manifest 引用的原字节。

这些检查验证了实际加载文件和动作映射。它们不等同于重新审计训练 reader 的所有标签时序，也不等同于训练模型与评测模型固定输入、固定噪声下的完整动作输出一致性证明。

## 6. 对低成功率的判断与未完成核验

另一项 soarm 官方 RoboTwin 后训练模型开发评测完整执行 500 场、成功 449 场（89.8%），说明已经检查的通用观测、模型调用、动作执行和任务判定流程能够支持高成功率。用于本报告的[官方模型完成回执](e1-15000-completed-20261013/official-baseline-verification.json)保留原字节；它不是本次 E1 的一部分，不进入 E1 分母。

该官方模型使用自己的绝对动作 norm，checkpoint 训练步数、训练范围与 E1 不同，跨主机初始 RGB 差异也按授权保留。因此 89.8% 对评测通用流程提供正向证据，不能直接量化 E1 训练方案的损失，也不能覆盖每个模型专属接口分支。

| 判断 | 当前证据与边界 |
| --- | --- |
| E1 评测拿错了 norm | 没有支持这一解释的证据；实际 runtime SHA、有效 YAML、统计形状与 CPU 往返已通过 |
| E1 把相对变化错误累计或给夹爪加了状态 | 已检查的实际逆变换与回执未发现这些错误；每 horizon 单次加回当前机械臂状态、夹爪绝对 |
| 低分来自初始化场景或指令明显不配对 | 本轮 500 个固定输入和 1500 张初始 RGB 已通过逐项核验；后续模型 RNG 不等同于 E0 历史流 |
| E1 训练代码已证实出错 | 尚未定位到具体错误。旧 Lab 的浮点图像缩暗缺陷不能外推为 E1 训练受影响；E1 原配置关闭图像增强 |
| E1 训练不足或训练范围不合适 | 属于待检验假设。现有 loss 与闭环分数不足以判断具体原因；正常训练配方差异也可能造成低分 |
| 导出 / 独立加载的完整动作等价 | 训练端尚未提供导出前、导出后及独立重载的固定输入/固定噪声完整动作审计。字节接收、参数逐值校验和 CPU 映射检查不能冒充它 |

下一项有针对性的核验是：以同一 RGB、关节、指令和显式噪声，对训练端模型、导出后模型及评测端独立加载模型比较规范动作 `[50,55]` 和物理动作 `[50,14]`，同时固定计算后端与数值条件，记录完整差值。该核验尚未执行，不在本报告中标记为通过，也不据本报告启动新实验。
