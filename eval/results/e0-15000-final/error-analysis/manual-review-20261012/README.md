## 整体介绍

本次对 E0 评测中的 20 个精选 Clean 案例进行了复核，其中 14 个失败案例已结合人工视频观察、关键截图和日志完成分析，6 个成功对照完成了非视频核对。已观察到的共性问题集中在接近时对位不准、夹持建立不足、放置偏移，以及释放后未充分退离便继续移动；笔记本、开关和微波炉还暴露出交互部位与接触方向选择不合适的现象。后续建议优先核对三视角图像、动作/夹爪映射和归一化链路，并对照成功示教检查接近、闭合、提起、释放、退离的完整时序；再开展保留关键动作段、基于允许示教统计的关键窗口采样等单变量实验。更频繁重新观察可作为通用执行窗口的独立对照。上述原因与改进效果尚待验证，精选案例比例不代表整体失败率。

## 覆盖与完成状态

20 个案例均来自 E0 Clean 评测，涉及 10 个任务。14 个失败案例已登记视频定位时间、用户回放描述与截图、日志事实、阶段初判和候选改进建议。原有 20 张内嵌图片、表格、数据验证与冻结窗格保留。

6 个成功对照（#11、13、15、17、19、20）只完成非视频核对，视频中的成功动作机制仍待复核；这些行的 Failure Stage 不适用。失败案例的部分时间点是代表性尝试或后续碰撞定位，并非全部都是首次偏差时刻，具体见表内说明。

已有分析中的双瓶 Clean/100010 与笔记本 Clean/100010 和本表重合；其余既有案例涉及不同任务或 Randomized 场景。比较时应同时核对 task、setting、seed 和运行段来源，不能仅按整数 seed 合并。

## 核心改进方向

1. **接近与夹持建立。** 检查目标位置、夹爪姿态、可达开口、闭合时机与提起顺序。瓶身中下部、薄缘或把手局部夹持是待验证的几何候选，不是通用抓取规则，也不能凭碰倒确诊视觉模块。
2. **放置、释放与退离。** 对照成功示教检查放置对齐、释放及避碰回撤，避免低位横移再次碰到已放物体。保持动作窗口末尾的释放与退离段，不将一律回到初始位姿作为修复方案。
3. **交互部位与方向。** 笔记本、开关和微波炉应核对功能部位、接触侧和铰链方向。放物入篮任务包含提篮，抓篮或提篮本身不能判为错误。文本歧义或 lift 用词尚未被证明是根因。
4. **训练与执行验证。** 先核三路图像的名称、顺序、同步、预处理，14 维动作/开合映射、训练与评测 norm 绑定及动作有效掩码；目前未确诊这些链路有错。示教核对后，可单独试基于允许示教自身统计的关键窗口采样。若当前只使用一条指令，再独立试匹配的 release seen 指令池采样。预测 50 步但只执行前 K 步再观察，需要作为改变执行协议的通用对照单列。
