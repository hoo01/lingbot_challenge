连接与评测
连接平台
在自己电脑运行 python eval/connect.py check 检查连接，再运行 python eval/connect.py tunnel 并保持终端打开。浏览器访问命令打印的地址，默认连接租用 5090。
使用网页
  1. 选择已注册模型，或上传完整合并权重、训练 CLI、归一化和导出收据后注册。
  2. 点击“新建评测”，选择任务、Clean/Randomized 和固定 seed，加入队列。
  3. Worker 按顺序执行。录像默认关闭，开启后为10 fps仿真时间原速。
  4. 打开报告，查看成功/有效回合、三相机、动作轨迹和可选录像，下载 CSV。
使用脚本
python eval/connect.py eval -- --checkpoint-id MODEL_ID --tasks click_bell --seeds 100010 --enqueue
去掉 --enqueue 可直接运行。脚本和网页使用同一服务器上的模型与队列。
统计口径
成功率 = 成功回合 / 有效策略回合。初始化失败和运行错误另列；固定 seed 评测不会自动补齐初始化失败。这里是开发场景评测。
模型与服务器配置
原始基座使用上游归一化，微调模型使用训练时绑定的 clean 数据统计量。推理固定为 FP32、256输入、执行50、10步flow。
连接地址、目录和端口配置在 eval/configs/servers.json；个人配置放在 servers.local.json。添加其他服务器并建立对应隧道后，可在上方选择并打开。详细命令和模型文件要求见 eval/README.md，基座成绩见 eval/results/baseline.md。
