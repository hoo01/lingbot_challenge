## 2. 任务说明

本项目面向桌面物体的双臂交接。一台SO101从臂抓取桌面上的绿色香蕉状物体，抬升并向另一台从臂递交；接收臂建立夹持后，取物臂退出，接收臂再将物体向桌面移动。

任务涉及两臂共享工作空间中的接近姿态、交接时序和交接后的独立持物。将取物设备记为从臂A、接收设备记为从臂B；A、B表示任务角色，不对应固定画面左右方向。

完整任务目标包括：A抓取并抬升物体，B接近并稳定夹持，A松开和退出，B将物体放稳后松爪撤离。

## 3. 数据与训练

数据来自本项目双SO101桌面交接任务的真机示范。按照LeRobot数据记录流程，以独立回合保存图像观测、机器人状态和对应动作，并记录回合结果、失败原因与采集配置。

模型以LingBot-VLA为起点进行全参数监督微调（SFT）。数据用于学习双臂抓取、接近、交接及后续转移的动作序列。此处说明真机Demo的训练方法；仿真50任务的训练数据、模型和成绩见[复现与调优说明](../04_复现与调优说明/reproduction_report.md)。

原始材料未提供真机示范条数、训练步数和具体学习率，本说明不据此填写数值。

## 4. Demo效果

随附视频为原文件，未在材料整理中转码、裁切或拼接。文件包含535帧画面，30fps，分辨率1280×612，视频轨时长约17.83秒。

以下阶段与效果沿用原项目说明的观察记录，时间为近似区间：

| 视频时间 | 执行阶段 | 可见结果 |
|---|---|---|
| 约0—3秒 | 接近与抓取 | A接近目标物体，夹持并将其抬离桌面 |
| 约3—9秒 | 双臂汇合 | 两台从臂末端在物体附近汇合，B的夹爪接近物体 |
| 约9—12秒 | 交接与分离 | A退出，物体由B独立夹持 |
| 约12—17.8秒 | 接收臂转移与下降 | B将物体移向桌面，末端接触区域受到遮挡 |

视频支持一次抓取、双臂交接和接收臂独立持物的展示。交接环节未见明显掉落；末段物体和夹爪的接触区域受机械臂遮挡，不能仅据该画面确认最终完整松爪放置。

提交材料包含1段演示视频，未提供重复尝试次数与完整任务成功次数，因此不将单段视频换算为成功率；17.83秒为视频时长，不作为实测任务节拍。

## 5. 技术方案

- **感知与数据记录**：使用任务图像观测及机器人状态，并通过LeRobot记录对应动作，按回合组织真机示范。
- **模型与推理**：采用真机数据全参数SFT后的LingBot-VLA，完成双臂任务的动作生成；具体模型参数和设备配置以本项目实际部署为准。
- **真机适配**：通过LeRobot对接两台SO101从臂的数据和设备接口，按取物臂与接收臂组织任务执行。
- **调试重点**：在B稳定夹持后再释放A；检查双臂共享工作空间、夹爪接近方向和线缆走向，低速验证交接区域。
- **改进方向**：补充能够同时看清物体、桌面及夹爪开合的视角，验证最终放稳、松爪和撤离；开展重复试验并记录完整任务成功率。
