# 第三方模块与使用位置

公开固定来源见ASSETS.md；随附源码许可保存在licenses目录。

| 模块 | 用途与交付 |
|---|---|
| LingBot-VLA v2 | 学生、训练、特征转换、优化器及推理；固定上游，随附Apache2.0许可 |
| RoboTwin 2.0 | 官方示范与50任务评测；实际任务／配置快照，随附MIT许可 |
| MoGe2 | 公开冻结深度模块；随附上游MoGe许可 |
| MoRGBD／LingBot-depth | 指定6B仓库的冻结深度教师；随附LingBot-depth许可 |
| DINO-video | 指定6B仓库的冻结视频教师与配置 |
| GroundingDINO Tiny | 原Clean RGB离线框检测，Transformers实现；不参与推理、不提供动作标签 |
| Qwen处理配置 | 随模型提供的tokenizer／processor，保留原来源 |
| CuRobo／SAPIEN／MPLib／OIDN | 规划、物理和渲染环境，按其公开分发和许可安装 |

外部视觉教师与检测器仅作用于原Clean示范；学生闭环只接收规定的RGB、关节和指令。检测框、仿真特权诊断与评测结果不进入测试时策略输入。

评测适配在src/eval_runtime，任务／配置快照在src/robotwin_overlay。适配包括分片、无专家开发评测、预测50执行25、关闭录像、首批输入／动作记录、有限值检查及超时／错误分类。加载显式保留FP32张量，记录实际processor和动作反归一化。任务动作控制、step_lim和成功条件保持冻结的RoboTwin实现。

源码许可与模型、数据、二进制的分发条件分别保存，资产准备时保留原model card、LICENSE与NOTICE。
