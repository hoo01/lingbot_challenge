从 checkpoint 到视频报告
  1. 上传完整模型目录，包含 safetensors、训练时的 CLI 配置和同一份归一化 JSON。
  2. 在「模型与数据」中注册，明确填写三个文件路径。
  3. 新建评测，固定任务、setting、seed 与执行动作块长度。
  4. GPU worker 自动领取任务；失败保留日志，取消保留已完成回合。
  5. 打开报告，查看各任务分母、回合视频、三相机图片和动作轨迹，下载 CSV。


统计口径
成功率 = 成功回合 / 有效策略回合。初始化失败和运行错误另列，不能当作策略失败，也不会换 seed 补齐。这里是固定 seed 的开发评测，不等同于官方专家筛选场景的完整榜单。
归一化文件
未经微调的原始基座使用仓库原文件；队友训练的 checkpoint 使用训练时绑定的 clean 数据统计量。不要混用。
访问与运行
页面通过 SSH 隧道访问；服务只监听 127.0.0.1。每张可见 GPU 对应独立 worker、锁和推理端口。新加卡后重启平台管理进程即可发现。
服务器路径：/root/shared-nvme/lingbot-eval。完整部署、重启与环境说明见项目 docs/evaluation_platform.md。
